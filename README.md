# Crave + Create — Smart Food & Recipe

An attractive, responsive Smart Food & Recipe portal built with **HTML, CSS and JavaScript**.

## Features
- Modern food-focused responsive UI
- Hero section
- Recipe categories
- Recipe search
- Category filtering
- Recipe cards with food images
- Favorite/heart interaction
- Full recipe popup with ingredients and cooking steps
- Kitchen tip section
- Newsletter subscription interaction
- Mobile navigation
- About section and footer

## Files
- `index.html`
- `style.css`
- `script.js`
- `images/` — offline SVG food images

## Run
Open `index.html` in VS Code and launch with Live Server, or simply open it in a browser.

## Hosting
This is a static website and can be hosted on GitHub Pages, Netlify or Vercel.

## Note
The newsletter form is frontend-only and does not send data to a real mailing service.
